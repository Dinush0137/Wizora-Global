# Wizora Global Website

A responsive, single-page HTML/CSS/JavaScript website based on the supplied **Wizora Global Website UI/UX & Architecture Specification** PDF and the later Premium Corporate visual direction.

## Included
- Responsive header and mobile navigation
- Hero section with custom CSS tech illustration
- About, mission, vision, core values, and editable stats
- Services & Expertise cards
- Our Clients Network section with map markers and client-name treatments
- Wizora Sync and Nexus Gateway product showcase
- Contact cards, WhatsApp links, and a mailto-based contact form
- Footer, quick links, social link placeholders, and floating WhatsApp action

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Before publishing
1. Replace `+94771234567` in `index.html` with the official WhatsApp number in international format (digits only in the URL).
2. Confirm `contact@wizoraglobal.com` and the company contact details.
3. Replace the illustrative client logo treatments with the original approved logo image files. Client names are included from the supplied reference image; the stylized wordmarks are placeholders, not official logo artwork.
4. Update the social profile links in the footer.
5. Confirm that any experience/project statistics are accurate before publishing.
6. The contact form currently opens the visitor's default email app. For server-side delivery, connect it to a backend or form service.

## Design
The PDF's original dark navy/teal palette is represented by a light Premium Corporate variant as requested in the conversation: white/light-blue backgrounds, navy typography, and blue accents. The requested sections and interaction concepts are retained.
